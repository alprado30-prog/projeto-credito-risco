# Projeto Avaliativo Módulo 1 - Pipeline de Risco de Crédito

**Curso:** Carreira Tech - Trilha Inteligência Artificial - Fundamentos de Programação, Dados e Machine Learning - S25134
**Instituição:** SCTEC / SENAI

**Objetivo:** Prever risco de inadimplência (loan_status) a partir de dados de clientes.

**O que foi feito:**
- Fase 1 - EDA: Análise exploratória
- Fase 2 - Data Prep: Limpeza de nulos e remoção de idades inválidas

- Fase 4 - Pipeline seguro com StandardScaler e OneHotEncoder
- Fase 5 - Modelagem com RandomForestClassifier
- Fase 6 - Validação com 93,17% de acurácia
